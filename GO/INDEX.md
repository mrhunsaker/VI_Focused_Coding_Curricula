# Go Topic Index

Use this index with the [Go curriculum overview](GO_README.md) and [complete Go lessons](lessons.md). The course introduces Go for services, command-line programs, and concurrent systems.

## Learning sequence

1. Go toolchain, modules, source files, and first program.
2. Variables, constants, types, and expressions.
3. Input/output and explicit conversion.
4. Boolean logic, decisions, and loops.
5. Arrays, slices, maps, and iteration.
6. Functions, multiple return values, and scope.
7. Structs, methods, and interfaces.
8. Packages, modules, and error handling.
9. Files and structured data.
10. Testing, formatting, and standard library use.
11. Integrated projects and capstone.

## Go-specific concepts

- go.mod, modules, packages, and imports.
- Static typing and short variable declarations.
- Slices, maps, arrays, and their semantics.
- Functions and multiple return values.
- Structs, methods, and interface satisfaction.
- Explicit error values and wrapping.
- Pointers and value semantics.
- defer and resource cleanup.
- Goroutines and channels as introductory concurrency concepts.
- gofmt, go test, and toolchain workflows.
