# Introductory Modules Index

These modules introduce focused areas of computing that complement the full programming-language curricula. They are not substitutes for the terminal prerequisite or the shared computing foundations.

## Modules

- [HTML and CSS: Web structure and presentation](HTML_CSS.md): semantic HTML, CSS rules, document structure, and accessible web content.
- [R: Statistical computing](R.md): R values and data structures, descriptive statistics, data import, and reproducible analysis.
- [SQL: Relational databases](SQL.md): relational models, queries, filtering, aggregation, joins, transactions, and safe data access.

## Suggested prerequisites

Complete the [Computing Foundations Primer](../FOUNDATIONS/unit-p-computing-foundations.md) and [Terminal Skills prerequisite](../TERMINAL/TERMINAL_README.md) before working through these modules. Basic file and folder navigation is assumed.
