# Introductory Modules Index

These modules introduce focused areas of computing that complement the full programming-language curricula. They are not substitutes for the terminal prerequisite or the shared computing foundations.

## Modules

- [Git: Version control](GIT.md): repositories, commits, branches, merges, remotes, pull requests, and reading diffs as text.
- [HTML and CSS: Web structure and presentation](HTML_CSS.md): semantic HTML, CSS rules, document structure, and accessible web content.
- [Markdown: Technical documentation](MARKDOWN.md): headings, lists, links, code blocks, tables, dialects, and screen-reader-friendly authoring.
- [R: Statistical computing](R.md): R values and data structures, descriptive statistics, data import, and reproducible analysis.
- [Regular expressions: Pattern-based text processing](REGEX.md): literals, character classes, quantifiers, groups, flags, dialects, and command-line tools.
- [SQL: Relational databases](SQL.md): relational models, queries, filtering, aggregation, joins, transactions, and safe data access.
- [Structured data formats: JSON, YAML, and TOML](STRUCTURED_DATA.md): syntax, data models, validation tooling, and format selection for each format.
- [Web accessibility: ARIA, WCAG, and accessible design](WEB_ACCESSIBILITY.md): the accessibility tree, WCAG principles, semantic HTML and ARIA, keyboard and focus, forms, and testing workflow.

## Suggested prerequisites

Complete the [Computing Foundations Primer](../FOUNDATIONS/unit-p-computing-foundations.md) and [Terminal Skills prerequisite](../TERMINAL/TERMINAL_README.md) before working through these modules. Basic file and folder navigation is assumed.

Learners new to version control should complete the [Git module](GIT.md) before modules that assume repository workflows, such as Web accessibility practice on hosted projects. The [Markdown module](MARKDOWN.md) is recommended before any module that asks for written documentation; the [Regular expressions module](REGEX.md) and [Structured data formats module](STRUCTURED_DATA.md) are independent of the others and can be studied in any order.
