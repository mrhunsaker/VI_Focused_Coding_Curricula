# Kotlin curriculum moved

Kotlin is now a standalone language curriculum rather than an optional Java supplement. Begin with the [Kotlin curriculum overview](../KOTLIN/KOTLIN_README.md), continue through the [Kotlin lessons](../KOTLIN/lessons.md), and use the [Kotlin topic index](../KOTLIN/INDEX.md).

Java knowledge is helpful for understanding JVM interoperability, but it is not a prerequisite for the Kotlin course.
