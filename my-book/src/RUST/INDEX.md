# Rust Topic Index

Use this index with the [Rust curriculum overview](rust_README.md) and [complete Rust lessons](lessons.md). The course introduces Rust's ownership model and systems-oriented programming practices.

## Learning sequence

1. Rust toolchain, Cargo projects, and first program.
2. Variables, mutability, types, and expressions.
3. Input/output, parsing, and error reporting.
4. Conditions, loops, and control flow.
5. Strings, vectors, slices, and collections.
6. Functions, ownership, borrowing, and references.
7. Structs, enums, and pattern matching.
8. Methods, traits, and generic concepts.
9. Error handling with Option and Result.
10. Files, modules, testing, and package management.
11. Integrated projects and capstone.

## Rust-specific concepts

- Cargo manifest and lockfile.
- Immutable bindings by default and explicit mut.
- Ownership, moves, borrowing, and lifetimes at an introductory level.
- Stack and heap concepts.
- String versus string slices.
- Vec<T>, slices, and iterators.
- Structs, enums, and exhaustive match.
- Traits, implementations, and generics.
- Option<T> and Result<T, E>.
- ? error propagation and recoverable errors.
- Unit tests, modules, and documentation.
