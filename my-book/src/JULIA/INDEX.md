# Julia Topic Index

Use this index with the [Julia curriculum overview](julia_README.md) and [complete Julia lessons](lessons.md). The course introduces Julia for numerical, scientific, and data-oriented computing.

## Learning sequence

1. Julia runtime, REPL, project, and first script.
2. Values, variables, types, and numeric expressions.
3. Input/output and conversion.
4. Boolean logic, conditionals, and loops.
5. Arrays, tuples, dictionaries, and iteration.
6. Functions, multiple dispatch, and scope.
7. Composite types and data modeling.
8. Files, exceptions, and structured data.
9. Packages, project environments, and reproducibility.
10. Testing, numerical analysis, and data processing.
11. Integrated projects and capstone.

## Julia-specific concepts

- Dynamic typing with a rich type system.
- REPL-driven exploration and script execution.
- Multiple dispatch and method definitions.
- One-based indexing and array-oriented operations.
- Tuples, named tuples, dictionaries, and arrays.
- Broadcasting and dotted operations.
- Composite types and constructors.
- Package environments using Project.toml and Manifest.toml.
- Performance considerations, compilation, and type stability.
- CSV and JSON processing through external packages.
