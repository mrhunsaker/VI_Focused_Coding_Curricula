# Swift Topic Index

Use this index with the [Swift curriculum overview](swift_README.md) and [complete Swift lessons](lessons.md). The course introduces Swift's type system and application-development foundations.

## Learning sequence

1. Swift toolchain, source files, and first program.
2. Constants, variables, types, and expressions.
3. Input/output and conversion.
4. Conditions, switch, and loops.
5. Strings, arrays, dictionaries, and sets.
6. Functions, parameters, and return values.
7. Structures, classes, properties, and methods.
8. Protocols, extensions, and value/reference semantics.
9. Optionals and error handling.
10. Files, Codable, testing, and packages.
11. Integrated projects and capstone.

## Swift-specific concepts

- let and var, type inference, and static typing.
- Optionals, optional binding, and safe unwrapping.
- Value semantics for structures and enums.
- Classes, reference semantics, and inheritance.
- Protocols, extensions, and generics.
- Arrays, dictionaries, sets, and collection operations.
- Codable for structured serialization.
- throws, do, try, and error propagation.
- Swift Package Manager and package structure.
- Structured concurrency concepts where appropriate.
