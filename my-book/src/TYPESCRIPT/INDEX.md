# TypeScript Index

Use this index to find the lesson that teaches a TypeScript feature, JavaScript runtime behavior, or typed development workflow. TypeScript checks source types before execution; its annotations do not validate external data at runtime. For definitions, see the [TypeScript glossary](../backmatter/GLOSSARY.md#typescript-glossary).
