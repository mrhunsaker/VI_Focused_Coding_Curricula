# C#: Lessons and Guided Practice

## Toolchain and first run

Install the .NET SDK. Create a console project with dotnet new console, then run it with dotnet run from the project directory. Use the SDK version documented by the course.

## Lesson 1: .NET and project structure

Learn the SDK, runtime, compiler, project file, entry point, and build/run cycle. Exercise: create and run a console project.

## Lesson 2: Variables and types

Study var inference, explicit types, numeric conversions, const, operators, and string interpolation. Exercise: calculate a total and print a labeled result.

## Lesson 3: Input and validation

Read console input as text, use TryParse, and distinguish missing, malformed, and out-of-range values. Exercise: reject invalid quantities with a useful message.

## Lesson 4: Control flow and methods

Use if, switch expressions, loops, parameters, return values, and scope. Exercise: implement a menu with explicit handling for unknown options.

## Lesson 5: Collections

Use arrays, List<T>, Dictionary<TKey,TValue>, and iteration. Exercise: count and summarize records while choosing a collection based on lookup needs.

## Lesson 6: Classes, records, and interfaces

Compare classes and records, properties, constructors, encapsulation, and interfaces. Exercise: model an immutable record and a service that processes it.

## Lesson 7: Exceptions, nullability, and LINQ

Enable nullable reference types, validate external values, handle expected exceptions, and use LINQ for readable transformations. Exercise: group and filter records.

## Lesson 8: Files, JSON, and async

Read/write text and JSON, understand serialization contracts, and introduce async/await for I/O-bound work. Exercise: load JSON records and report malformed input.

## Lesson 9: Testing and debugging

Use a unit-testing framework, debugger, and diagnostics. Test ordinary, boundary, empty, and invalid inputs. Add regression tests for corrected defects.

## Lesson 10: Capstone

Build a .NET command-line data manager with validation, records, collections, JSON persistence, tests, and a README.
