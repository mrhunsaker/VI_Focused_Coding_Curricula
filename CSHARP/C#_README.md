# C# Curriculum

C# is a modern managed language for .NET services, web applications, desktop software, cloud systems, and Unity games.

## Course structure

A complete introductory sequence aligned to Python Units 0–11: setup; foundations; numeric computation; control flow; data structures; input and iteration; functions; object-oriented design; files and exceptions; testing and data analysis; projects; and capstone.

The same core problem contexts recur across languages so students can focus on syntax, types, runtime behavior, libraries, and idioms rather than repeatedly learning new examples.

## Environment

Install the .NET SDK. Create a console project with `dotnet new console -n CourseApp`, enter the folder, and run `dotnet run`.

Complete the shared [IDE setup lesson](../DEVELOPMENT/IDE_SETUP.md) and [terminal prerequisite](../TERMINAL/TERMINAL_README.md). The course supports keyboard-first work with screen readers, braille displays, magnification, or other access technology.
