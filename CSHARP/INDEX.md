# C# Topic Index

Use this index with the [C# curriculum overview](csharp_README.md) and [complete C# lessons](lessons.md). The course targets modern C# and .NET application development.

## Learning sequence

1. .NET toolchain, projects, and first console application.
2. Variables, types, literals, and expressions.
3. Console input/output and explicit conversions.
4. Boolean logic, decisions, and pattern matching.
5. Loops, arrays, strings, and collections.
6. Methods, parameters, return values, and scope.
7. Classes, objects, properties, and constructors.
8. Inheritance, interfaces, and polymorphism.
9. Files, exceptions, and structured data.
10. Testing, debugging, and data processing.
11. Integrated projects and capstone.

## C# and .NET concepts

- .NET SDK, runtime, project files, and dotnet CLI.
- Value types, reference types, nullable reference types, and conversions.
- string, arrays, List<T>, dictionaries, and generic collections.
- Methods, overloads, optional parameters, and expression-bodied members.
- Classes, records, properties, constructors, and access modifiers.
- Interfaces, inheritance, and polymorphism.
- Exceptions, file APIs, and resource disposal.
- LINQ and collection processing.
- Unit testing, compiler diagnostics, and debugging.
