# Round 4 Report: Java Rewrite (5 November 2026)

## What was done

All 57 lessons in `JAVA/lessons.md` were rewritten: lesson-specific concept text, a complete worked program, captured output, common mistakes, activities, and accessibility practice, all using the shared datasets and Java features (static typing, `Scanner`, records, `Optional`, overloading in place of default arguments, checked and unchecked exceptions, try-with-resources, `java.nio.file`).

Measured on the file as written to disk:
- 57 of 57 distinct in every section (concept, worked example, expected output, mistakes, activities, accessibility). Before: 12 distinct mistakes, 12 distinct activities, and 1 distinct accessibility text.
- The worked programs average about 53 lines (they were about 3 lines before).
- All 57 lessons have the nine sections in order; 12 unit headings with overviews; the AI policy section is present; no leftover boilerplate; no broken relative links.
- `scripts/check_java_examples.py` (patched copy using `--release 21`): 57 of 57 examples compile and run.

Each "Expected Behavior or Output" block is the captured output of that lesson's program (with the scripted standard input shown for interactive lessons). Java prints the shared tip as 3.68, and Lesson 2.1 explains why other languages print 3.67.

Lessons 8.5, 10.4, and 11.2 include a small teaching JSON helper because the Java standard library has none. It was tested with a round trip and six malformed inputs only.

The generator scripts are in `java-generator/`.

## Limits

- Verified on JDK 21, not the JDK 25 baseline. The programs avoid preview features, but the checker has not been run on JDK 25.
- The repository checker compiles and runs the examples but does not compare their output with the lesson text.
- Not tested with screen readers or braille displays.
- Only `JAVA/lessons.md` was rewritten. The four grouped unit files (`JAVA/unit*.md`) are unchanged and still contain older, non-canonical examples; the Java INDEX links to them. A decision is needed on whether to update or retire them.
