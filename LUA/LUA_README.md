# Lua Curriculum

Lua is a lightweight embeddable scripting language used in games, embedded applications, configuration, automation, and extensible software.

A complete introductory course aligned to Python Units 0–11. Familiar problem contexts recur so learners can focus on Lua's tables, dynamic values, functions, metatables, modules, and runtime behavior.

## Environment

Install Lua 5.4 from lua.org or your operating-system package manager. Verify `lua -v`; run a file with `lua main.lua` and experiment in the interpreter.

Complete the shared [IDE setup lesson](../DEVELOPMENT/IDE_SETUP.md) and [terminal prerequisite](../TERMINAL/TERMINAL_README.md).
