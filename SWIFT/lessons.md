# Swift: Lessons and Guided Practice

## Toolchain and first run

Install the Swift toolchain appropriate to the operating system. Use swift for a single source file and Swift Package Manager for a maintainable project. Confirm platform and SDK requirements before using Apple-only frameworks.

## Lesson 1: Toolchain and packages

Study the compiler, package manifest, source layout, and build/test commands. Exercise: create a package and run its starter program.

## Lesson 2: Bindings and types

Compare let and var, inferred and explicit types, numeric conversions, and string interpolation. Exercise: compute a total and explain mutability choices.

## Lesson 3: Optionals

Understand optional types, nil, if let, guard let, optional chaining, and nil coalescing. Exercise: parse an optional field and provide a safe fallback.

## Lesson 4: Control flow and functions

Use if, switch, for-in, while, function parameters, return values, and argument labels. Exercise: implement validated menu selection.

## Lesson 5: Collections

Use Array, Dictionary, Set, iteration, and higher-order methods. Exercise: group records and summarize a collection.

## Lesson 6: Value semantics

Study structs, enums, associated values, raw values, and copying behavior. Exercise: model a measurement and its unit with an enum.

## Lesson 7: Classes and protocols

Compare classes and structs, identity, inheritance, protocols, extensions, and composition. Exercise: define a protocol for a reportable record.

## Lesson 8: Errors, files, and Codable

Use throwing functions, do/catch, file APIs, and Codable for structured serialization. Validate untrusted data and distinguish decoding failure from invalid business values.

## Lesson 9: Concurrency and tests

Introduce async/await, tasks, actors, cancellation, and data-race safety. Use XCTest or Swift Testing as appropriate. Exercise: test a pure function and explain asynchronous error handling.

## Lesson 10: Capstone

Build a cross-platform command-line record processor with optionals, value types, collections, Codable persistence, tests, and documented platform assumptions.
