## Kotlin language concepts

- **Values and variables:** val, var, type inference, explicit types, mutability.
- **Type system:** numeric types, strings, characters, Boolean values, conversions, and nullable types.
- **Null safety:** nullable declarations, safe calls, Elvis expressions, and not-null assertions.
- **Control flow:** Boolean expressions, if, when, loops, ranges, and iteration.
- **Collections:** arrays, read-only and mutable lists, sets, maps, and collection operations.
- **Functions:** parameters, return types, default arguments, named arguments, and scope.
- **Object-oriented programming:** classes, properties, constructors, methods, inheritance, interfaces, and data classes.
- **JVM interoperability:** Kotlin and Java libraries, JVM execution, and build tooling.
- **Files and resources:** reading and writing text, resource management, and error handling.
- **Testing and projects:** testable functions, assertions, project organization, and incremental development.

## Accessibility and workflow

The curriculum emphasizes keyboard-first editor use, explicit discussion of punctuation and nesting, text-based input and output, and independent interpretation of compiler diagnostics. For editor selection and accessibility evaluation, see [Development editors and IDEs](../DEVELOPMENT/IDE_SETUP.md).
