# Introduction to Computer Science with Python

## Accessible, Screen-Reader-Friendly Curriculum

This curriculum introduces programming and computer science using Python. It is designed for learners who use screen readers and emphasizes text-based interaction, keyboard-first development, and explicit navigation.

**Target audience:** Beginning programmers who rely on screen readers, including NVDA, JAWS, VoiceOver, or Windows Narrator.

## Course sequence

| Unit | Focus |
|---|---|
| Unit 0 | Setting up an accessible Python development environment |
| Unit 1 | Foundations of computing and getting started with Python |
| Unit 2 | Simple programs and numeric computations |
| Unit 3 | Control flow, decisions, and loops |

| Units 7–9 | Classes, object-oriented programming, files, exceptions, and testing |

## Accessibility and development approach

- Use Visual Studio Code's Screen Reader Optimized Mode.
- Configure the screen reader to announce indentation changes; Python uses indentation to define code blocks.
- Navigate and operate the editor and terminal with the keyboard.
- Run programs and inspect output in a text-based terminal.
- Treat error messages and debugging as part of the learning process.

## Development environment

The setup unit provides instructions for installing Python 3 and Visual Studio Code, configuring screen-reader support, and verifying the development environment.
