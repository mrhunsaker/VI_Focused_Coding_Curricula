# Terminal Skills: Bash and PowerShell

## Preliminary prerequisite for every language

Complete this course before beginning any language curriculum. A terminal is a text interface for navigating files, running compilers and interpreters, managing projects, and reading diagnostics.

## Outcomes

Identify the current directory; list files; change directories; use absolute and relative paths; create and inspect files and folders; copy, move, rename, and safely delete items; inspect command help; run a program; and recover from common navigation errors.

## Lesson sequence

1. Shell, prompt, command, argument, option, path, and working directory.
2. Current location and directory listings.
3. Absolute paths, relative paths, parent directory, and home directory.
4. Creating directories and files.
5. Copying, moving, renaming, and deleting safely.
6. Reading text files and searching directory contents.
7. Command help, quoting, spaces, wildcards, and completion.
8. Running a program and interpreting exit status.
9. Environment variables and PATH.
10. Integrated project-navigation practice.

Practice in a dedicated directory. Read each command before pressing Enter. List a target before deleting it. Avoid recursive force-delete options while learning. Screen-reader users should read the prompt, command history, and output sequentially. Complete [Bash](bash.md) and [PowerShell](powershell.md) lessons before proceeding.
