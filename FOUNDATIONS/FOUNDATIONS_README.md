# Foundations: Computing Concepts Before Any Language

Unit P is a language-neutral primer that every learner completes **before Unit 0 of any language track**. It teaches the vocabulary and background that all thirteen general-purpose languages share, so each language track can concentrate on its own syntax and rules.

- [Unit P: Computing Foundations Primer](unit-p-computing-foundations.md)

## Lessons

- P.1 What a Computer Does
- P.2 Representing Information as Bits
- P.3 Algorithms, Pseudocode, and Tracing
- P.4 The Shared Vocabulary of Programming
- P.5 From Source Code to Running Program
- P.6 Files, Data Formats, and Reading Code Without Sight

## Design notes

- No diagrams, charts, or color cues. Structure is conveyed in prose, numbered lists, and traces written as sentences.
- Binary is introduced through braille cells, which are bit patterns that a learner can feel.
- Examples use the shared course datasets (student Avery, the tip calculator, the four scores, the inventory, the text sample).
- The unit follows the standard lesson template and the course AI policy.
- The accessibility practices in the unit are design intentions. They have not been tested with named screen readers or braille displays.
