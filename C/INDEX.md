# C Topic Index

Use this index to locate topics in the [C curriculum](c_README.md) and [complete C lessons](lessons.md). The course targets modern C and emphasizes explicit memory, types, and program behavior.

## Learning sequence

1. Computing foundations, source files, compiler, and first C program.
2. Variables, constants, fundamental types, expressions, and conversions.
3. Standard input and output, format specifiers, and input validation.
4. Boolean expressions, decisions, and control flow.
5. Loops, counters, accumulators, and nested repetition.
6. Arrays, strings, and indexed data.
7. Functions, parameters, return values, and scope.
8. Pointers, addresses, and the relationship between arrays and pointers.
9. Structures, enums, and user-defined data.
10. Dynamic memory, allocation, deallocation, and ownership discipline.
11. Files, error handling, testing, and integrated projects.

## C-specific concepts

- Compilation and linking; compiler diagnostics and warning flags.
- Integer and floating-point types, conversions, and overflow considerations.
- Format strings and safe input handling.
- Array bounds and null-terminated character strings.
- Function declarations, definitions, and header files.
- Pointers, dereferencing, pointer arithmetic, and NULL.
- struct, enum, typedef, and modular interfaces.
- Dynamic allocation with malloc, calloc, realloc, and free.
- File streams and return-value-based error handling.
- Undefined behavior and the importance of warnings and testing.
