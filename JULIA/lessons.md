# Julia: Lessons and Guided Practice

## Toolchain and first run

Install a stable Julia release. Learn to use the REPL for experiments and scripts for repeatable programs. Create a project environment and declare dependencies in its project file.

## Lesson 1: REPL, scripts, and environments

Distinguish interactive expressions from source files and package projects. Exercise: run the same calculation in the REPL and from a script.

## Lesson 2: Bindings, types, and numbers

Study assignment, basic types, numeric promotion, precision, strings, and missing values. Exercise: calculate a mean and explain the numeric type of each intermediate result.

## Lesson 3: Functions and multiple dispatch

Define functions, methods, argument types, and return behavior. Explain how dispatch selects a method based on argument types. Exercise: implement methods for two meaningful input types.

## Lesson 4: Arrays and broadcasting

Use vectors, matrices, ranges, indexing, slicing, and dot-broadcasting. Exercise: transform a measurement vector and summarize dimensions and units.

## Lesson 5: Control flow and comprehensions

Use conditions, loops, generators, and comprehensions. Exercise: filter values and calculate summary statistics.

## Lesson 6: Composite data

Use tuples, named tuples, dictionaries, structs, and mutable structs. Exercise: model a measurement with value, unit, timestamp, and source.

## Lesson 7: Modules, packages, and data

Organize code into modules, manage packages, and read structured data. Exercise: load a small dataset and validate its schema.

## Lesson 8: Performance and type stability

Understand compilation latency, allocations, specialization, and type stability. Measure before optimizing. Exercise: compare two implementations with a repeatable benchmark.

## Lesson 9: Testing and reproducibility

Use the Test standard library, deterministic random seeds, and documented environments. Exercise: test numeric edge cases and reproduce a result from a clean environment.

## Lesson 10: Capstone

Build a numerical analysis or simulation tool that loads data, validates units, computes results, and writes a text report with reproducible settings.
