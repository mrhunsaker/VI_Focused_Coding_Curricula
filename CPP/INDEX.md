# C++ Topic Index

Use this index with the [C++ curriculum overview](cpp_README.md) and [complete C++ lessons](lessons.md). The course uses modern C++ and emphasizes resource safety, standard-library abstractions, and clear program design.

## Learning sequence

1. Toolchain, compilation, source files, and first program.
2. Variables, fundamental types, constants, and expressions.
3. Input, output streams, and conversions.
4. Boolean logic, decisions, and loops.
5. Strings, arrays, and standard containers.
6. Functions, parameters, return values, and scope.
7. References, pointers, and object lifetime.
8. Classes, objects, constructors, and encapsulation.
9. Inheritance, polymorphism, and interfaces.
10. Files, exceptions, and resource management.
11. Algorithms, testing, and integrated projects.

## C++-specific concepts

- C++20 compilation and standard-library headers.
- std::cin, std::cout, and stream state.
- std::string, std::vector, std::array, and associative containers.
- References, pointers, const, and lifetime.
- Classes, access control, constructors, and member functions.
- RAII and deterministic resource management.
- Exceptions and error-handling design.
- Templates and standard algorithms at an introductory level.
- Smart pointers and ownership-aware design.
- Build, compile, link, and test workflows.
