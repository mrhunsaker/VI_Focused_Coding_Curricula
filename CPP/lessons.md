# C++: Lessons and Guided Practice

## Toolchain and first run

Install GCC, Clang, or MSVC. Compile with a modern language standard and warnings enabled. Keep source, build configuration, and tests in a project directory.

## Lesson 1: Compiler and build workflow

Study source files, headers, translation units, linking, and the main function. Exercise: compile a small program and explain each build stage.

## Lesson 2: Types, expressions, and I/O

Learn fundamental types, const, auto, conversions, operators, streams, and string handling. Exercise: calculate a total and format a readable report.

## Lesson 3: Control flow and functions

Use if, switch, loops, function declarations, overloads, and scope. Exercise: split input, validation, calculation, and output into functions.

## Lesson 4: Strings and containers

Practice std::string, std::vector, std::array, std::map, and iteration. Exercise: summarize a sequence and explain the container choice.

## Lesson 5: References, pointers, and lifetime

Distinguish references, raw pointers, null pointers, and object lifetime. Explain invalidation and dangling references. Exercise: pass data by const reference and avoid unnecessary ownership transfer.

## Lesson 6: Classes and encapsulation

Define classes, constructors, access control, invariants, and member functions. Exercise: model a record with validated construction.

## Lesson 7: RAII and smart pointers

Use deterministic resource management, std::unique_ptr, std::shared_ptr only when shared ownership is justified, and scope-based cleanup. Exercise: manage a resource without a manual cleanup branch.

## Lesson 8: Templates and algorithms

Study function/class templates, generic constraints, iterators, and standard algorithms. Exercise: transform and filter a collection using standard algorithms.

## Lesson 9: Files, exceptions, and testing

Read and write files, handle exceptions at appropriate boundaries, and write tests for ordinary and boundary behavior. Exercise: load records and report invalid rows.

## Lesson 10: Capstone

Build a text-based inventory, simulation, or measurement tool with classes, standard containers, RAII, file handling, and tests. Document performance and ownership decisions.
